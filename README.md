# movie-swipe-backend

Backend for the MovieMatch revival: one Supabase project (Postgres with pgvector, Auth, Realtime, Edge Functions, Cron and Queues), TypeScript end to end.

## Docs

- [Data model](docs/data-model/README.md): every table for the first release, how they interact, and where later features plug in. Reference DDL in [schema.sql](docs/data-model/schema.sql).
- [Revival plan](docs/revival-plan/README.md): audit of the old app and server, stack choice, catalog, deck engine, game design, roadmap.
- [Monetization options](docs/monetization/README.md): free vs Host Pro, family modes, packs, kids' safety.
